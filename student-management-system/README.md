# 🎓 Student Management System

A simple command-line **Student Management System** built in Python using Object-Oriented Programming concepts. This project allows users to manage student records through an interactive menu-driven interface.

## 📋 Features

- **Add Student** – Add new student records with Name, Age, Department, and Marks
- **View All Students** – Display all student records in a readable format
- **Search Student** – Look up a specific student's details
- **Update Marks** – Modify an existing student's marks
- **Delete Student** – Remove a student record from the system
- **Menu-Driven Interface** – Simple numbered menu for easy navigation

## 🛠️ Technologies & Concepts Used

- **Python 3**
- **Object-Oriented Programming (OOP)** – Classes and objects to model student records and operations
- **Menu-driven loop** – Continuous `while` loop with `if-elif` based menu navigation
- **In-memory data storage** – Student records are stored in a list/dictionary during runtime (data resets when the program exits)

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/mani-cse/python-projects.git
   cd python-projects
   ```
2. Run the script:
   ```bash
   python student_management_system.py
   ```
3. Follow the on-screen menu to Add, View, Update, or Delete student records.
